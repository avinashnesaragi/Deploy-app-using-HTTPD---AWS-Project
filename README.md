# Deploy Application Using Apache HTTPD on AWS EC2

## Project Overview

This project demonstrates deployment of a static web application on an AWS EC2 instance using Apache HTTP Server (HTTPD).

## Technologies Used

- AWS EC2
- Red Hat Enterprise Linux
- Apache HTTPD
- Git and GitHub
- SSH

## Deployment Steps

1. Created an AWS EC2 instance.
2. Connected to the instance using SSH from a Mac terminal.
3. Installed Git and Apache HTTPD.
4. Downloaded the application source code from GitHub.
5. Deployed the website files to `/var/www/html`.
6. Started the Apache HTTPD service.
7. Configured HTTP access through the EC2 Security Group.
8. Accessed the deployed application through the EC2 public IP address.
